# Dune II 3D

## Lessons

- When a feature's behaviour or look is in question, follow Westwood's 1992 RTS as released on the Sega Mega Drive/Genesis (*Dune: The Battle for Arrakis*), which this game remasters; the PC version's rules are used only where the spec says so (§1, e.g. the tech tree). Not Dune 2000 or C&C; offer other styles only as options (e.g. fog of war is an option, the shroud the default).
- When the original game's own files come up, support the English copy only; French and German copies are not wanted.
